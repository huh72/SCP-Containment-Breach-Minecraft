# SCP-Containment-Breach-Minecraft
A remake of SCP Containment Breach in Minecraft.

The gamemode is based on the works of the SCP Foundation community ([https://scpfoundation.net/](https://scpfoundation.net/)), SCP Containment Breach game (https://github.com/Regalis11/scpcb), SCP Containment Breach Ultimate Edition mod and SCP Containment Breach Director's cut mod.

Shaders were taken from JNNGL$4.

The project is currently under early development.
